# Amazon SDE-1 Interview Preparation Guide

## Overview
Amazon's SDE-1 interviews heavily focus on Data Structures, Algorithms, and the famous Amazon Leadership Principles (LPs). You need to be prepared to answer behavioral questions using the STAR method while tying them back to the LPs.

## Key Leadership Principles for SDE-1
- **Customer Obsession**: Start with the customer and work backwards.
- **Ownership**: You are an owner. Never say "that's not my job."
- **Deliver Results**: Focus on the key inputs and deliver them with the right quality and in a timely fashion.

## Technical Rounds
Expect 2-3 technical rounds focusing on:
- Arrays, Strings, and HashMaps (very common)
- Trees and Graphs (BFS/DFS)
- Object-Oriented Design (basic principles)

## Tips
- Always write production-ready code.
- Communicate your thought process clearly before writing any code.
- Prepare at least two stories for every Leadership Principle using the STAR format (Situation, Task, Action, Result).

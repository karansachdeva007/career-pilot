# Flipkart Interview Preparation Guide

## Overview
Flipkart, India's leading e-commerce company, has a rigorous interview process focused on problem-solving, algorithms, and machine coding.

## Key Focus Areas
- **Machine Coding**: A unique round where you are given a problem statement and asked to build a working, object-oriented solution within 90-120 minutes.
- **Data Structures and Algorithms**: Heavy focus on Graphs, DP, and Trees.
- **Problem Solving**: Expect complex, scenario-based algorithmic problems.

## Interview Process
- **Online Assessment**: Coding questions on platforms like HackerRank.
- **Machine Coding Round**: The defining round for SDE-1/2 roles. Focus on OOPs, design patterns, and working code.
- **PS/DS Round**: Standard algorithmic problem solving.
- **Hiring Manager Round**: Behavioral, cultural fit, and deep dive into past projects.

## Tips
- For the Machine Coding round, practice building small CLI applications with clean class structures and interfaces.
- Focus on modularity, extensibility, and separation of concerns.

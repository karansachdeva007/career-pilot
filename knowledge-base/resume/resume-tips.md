# Top Resume Tips for Software Engineers

## 1. Keep it to One Page
Unless you have 10+ years of highly relevant experience, your resume should fit on a single page. Recruiters spend only 6-10 seconds on the first pass.

## 2. Use the XYZ Formula for Bullet Points
Google famously recommends the formula: "Accomplished [X] as measured by [Y], by doing [Z]."
**Example**:
- *Bad*: "Improved database performance."
- *Good*: "Reduced average API latency by 40% (Y) saving $500/month in server costs (X) by implementing a Redis caching layer and optimizing complex SQL queries (Z)."

## 3. Emphasize Impact, Not Just Duties
Don't just list what you did. Explain the impact it had on the business or the team. Quantify whenever possible (dollars, percentages, time saved, users affected).

## 4. Tailor the Skills Section
Put the technologies you are strongest in first. Don't list 30 different languages and tools; it makes you look like a jack-of-all-trades and master of none. If you only used a tool once in college, don't list it as a primary skill.

## 5. Include Links
Always include a link to your LinkedIn, GitHub, and Portfolio (if you have one). Make sure your GitHub has pinned repositories that represent your best work.
